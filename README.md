# ZONE XI — 축구 전술 실험실

> **"당신은 어디를 포기하겠습니까"**
> 2026 월드컵 데이터 기반, 브라우저에서 바로 플레이하는 **축구 전술 실험실**.
> 세로형 축구장을 타일로 나눠 선수별 활동 영역을 색칠하면, 판이 즉시 반응해
> 커버리지의 강점·빈틈을 보여주고 리포트 카드를 산출합니다.

감독이 된 것처럼 11명의 활동 영역을 직접 칠하고, **공백(빈 구역)** 과 **과밀(겹친 구역)** 이
실시간으로 드러나는 것을 보며 전술을 다듬는 인터랙티브 웹서비스입니다.

## 🎯 핵심 루프

```
색칠  →  즉시 반응(공백·과밀이 눈에 보임)  →  리포트 카드로 결과 확인  →  다시 조정
```

- **규칙이 아니라 반응으로 알려줍니다.** "여기를 지켜라"가 아니라, 칠하면 공백·과밀이 드러날 뿐입니다.
- **정답이 아니라 결과를 줍니다.** 승률·수비 성공률 같은 **예측은 하지 않습니다.** 근거만 서술합니다.
- **측정한 것만 말합니다.** 위험 가중치는 **2026 월드컵 결승·3·4위전 2경기의 슈팅 채널 분포**에서 나옵니다.

## 🕹️ 사용 방법

1. **랜딩** → `시작하기`
2. **설정** → 포메이션 선택(4-3-3 / 4-4-2 / 3-5-2) → `이 배치로 시작` (또는 `건너뛰기`로 4-3-3 즉시)
3. **전술판** (핵심 화면)
   - 좌측 **선수 칩**에서 선수를 고른 뒤, 판을 **드래그**해 활동 영역을 칠합니다.
   - 도구: **브러시**(드래그) / **사각**(범위 일괄, `Shift` 드래그로도 가능) / **지우개**
   - **밀집도 뷰**로 전환하면 0명(공백·붉은색)·3명↑(과밀·주황)이 히트맵으로 보입니다.
   - **[공격 시 전개]** 로 국면을 바꿔 공격 시 전진할 영역을 따로 그릴 수 있습니다.
   - 타일에 마우스를 올리면 우측 패널 하단 **정보 시트**(구역 이름·위험 가중치·근거·역할·현재 커버)가 뜹니다.
   - 우측 **실시간 피드백**에서 면적 커버·**위험 가중 커버**·위험 구역·과밀·좌우 균형이 즉시 갱신됩니다.
4. **리포트 카드** → 성향 태그 · **가장 가까운 형태** · 밀집도 지도 · 발견 · 제안 · 근거 · 지표 6종

> 💡 GK(골키퍼)는 자기 골문 앞에 **자동 배치·잠금**되며, 사용자는 10명만 칠합니다.

### ⭐ 핵심 메커니즘 3가지

- **페인트 예산 (A)** — 선수당 `floor(칸수/10)` = 14×7에서 **9칸**. 10명×9=90 < 98이므로 **최소 8칸은 필연적으로 공백**입니다. "전부 칠하면 최고점"이 아니라 **"어디를 비울까"** 를 고르는 게임이 됩니다. 칩마다 예산 게이지, 팀 총 예산 바가 있고, 소진되면 색칠이 차단됩니다. (빈 칸은 실패가 아니라 배분 — 그래서 헤드라인은 원시 공백 수가 아니라 **위험 구역 N곳**을 강조합니다.)
- **위험 가중 커버리지 (C)** — `Σ(덮인 타일 가중치) / Σ(전체 가중치)`. 면적 커버와 **나란히** 노출됩니다. *가중 > 면적* 이면 중요 구역을 우선 덮은 것, *가중 < 면적* 이면 안전지대만 덮어 중요한 곳에 빈틈이 있다는 뜻입니다.
- **형태 유사도 (B)** — 15구역 커버 분포를 실측 팀의 **수비 커버 프로파일 근사**와 코사인 비교해 "가장 가까운 형태 — 스페인 72% (견고한 블록)"처럼 보여줍니다. **수비 국면 + 팀 예산 50% 이상**에서만 노출되며, 스페인·아르헨티나는 요약 근거라 **"요약 근사" 뱃지**가 붙습니다. **"형태가 유사합니다"까지만** — 우열·승률 예측은 하지 않습니다.

## 📊 무엇을 "데이터"로 쓰는가

| 데이터 | 출처 | 쓰임 |
|---|---|---|
| **15구역 위험 가중치** | 결승 + 3·4위전 2경기 슈팅 채널 분포 | 공백이 얼마나 "위험한지" 판정 (`att_C`=1.00 최고 위험 등) · 위험 가중 커버(C) 계산 |
| **슈팅 채널 분포 근거 문구** | 동일 2경기 | 리포트/바텀시트의 검증 가능한 근거 서술 |
| **팀 수비 커버 프로파일** | 스페인·아르헨티나(요약 근사)·프랑스·잉글랜드(리포트) | 형태 유사도(B) 비교 기준 벡터 |
| **성향 태그 실측 대응** | 스페인·프랑스·아르헨티나 배치 경향 | 사용자 배치를 실측 팀 성향에 대응 |

측정하지 않은 값(승률·개인 기량·압박 강도)은 **예측하지 않습니다.** 이 한계는 랜딩·리포트 하단에 상시 명시됩니다.

## 🛠 기술 스택

- **React 18 + TypeScript + Vite**
- **Tailwind CSS**
- **Zustand** (전역 상태) — 백엔드·외부 API·API 키 **없음**. 전부 클라이언트에서 규칙 기반으로 계산합니다.
- 판 렌더링: DOM 그리드(14×7=98타일) + Pointer Events 페인팅

> 별도 설치·회원가입·결제·API 키 없이 브라우저에서 바로 플레이 가능합니다.

## 📐 지표 정의 (모두 규칙 기반, 예측 아님)

- **면적 커버리지 %** — 최소 1명이 덮은 타일 비율
- **위험 가중 커버리지 % (C)** — `Σ(덮인 타일 가중치) / Σ(전체 가중치)`. 면적 커버와 상호보완
- **위험 구역 수** — 가중치 ≥ 0.30 이면서 커버 비율 < 0.34(공백)인 구역 수
- **과밀 칸 수** — 한 타일을 3명 이상이 덮은 칸 수 (경고가 아니라 "깊이/여유" 정보)
- **좌우 균형** — 중앙을 제외한 좌·우 질량의 편차
- **예산 사용률 (A)** — 팀이 쓴 칸 / 팀 총 예산(90). 국면별 독립
- **형태 유사도 % (B)** — 15구역 커버 벡터와 팀 수비 프로파일 근사의 코사인 유사도

성향 태그: `견고한 블록` · `하이 리스크` · `중앙 봉쇄` · `균형형` · `표준형`
